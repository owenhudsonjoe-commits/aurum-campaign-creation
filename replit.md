# Aurum — Fashion E-Commerce

A React + TanStack Router fashion e-commerce storefront for the Aurum brand, handcrafted in Lahore.

## Stack

- **Framework**: React 19 + TanStack Router + TanStack Query
- **Build tool**: Vite 7 (via `bunx vite dev`)
- **Styling**: Tailwind CSS v4 + Radix UI components (shadcn/ui pattern)
- **3D**: Three.js + React Three Fiber
- **Forms**: React Hook Form + Zod
- **Runtime**: Bun

## Running the app

```bash
bunx vite dev
```

Runs on port 5000. The workflow "Start application" is already configured to do this.

## Project structure

- `src/routes/` — TanStack Router file-based routes (index, shop, product, cart, checkout, wishlist, bespoke, sale, track)
- `src/components/` — Shared components (Nav, Footer, ProductCard, etc.) and `ui/` for shadcn primitives
- `src/assets/` — Product and brand images
